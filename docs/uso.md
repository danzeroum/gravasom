# Notas de uso

Uma linha por incômodo, escrita por quem usa o app no dia a dia. Os agentes leem este arquivo antes de cada onda; o que se
repete sobe de prioridade. Sem este arquivo preenchido, a prioridade vem do plano (`Gravasom v2 — validação das ideias e plano`).

Formato: `data · o que incomodou · onde`

| Data | O que incomodou | Onde |
| --- | --- | --- |
| _(ainda sem notas)_ | | |

## Como usar este arquivo

- Escreva o sintoma, não a solução ("não achei a parte da reunião de terça", e não "faltou um botão de busca").
- "Onde" é a tela ou a situação (biblioteca, player, gravando com a tela apagada, notificação...).
- A regra de corte do plano vale aqui: funcionalidade que você não usou em quatro semanas volta para discussão.

> **Estado em 2026-10-08:** o arquivo não existia no repositório quando a Onda 1 começou (ele é entregável da Onda 0, que
> não foi fechada). Foi criado vazio, no modelo acima. A Onda 1 portanto partiu do plano, sem notas de uso.
